## 文档维护约定

- 文档只描述当前状态
- 不记录过程性说明和阶段性备注
- 新增页面时同步更新 `page-relationships.md`
- 调整结构时同步更新 `project-structure.md`
- 调整 mock-server 时同步更新 `mock-server-guide.md`
- 调整 token 规则时同步更新 `token-usage-guide.md`
