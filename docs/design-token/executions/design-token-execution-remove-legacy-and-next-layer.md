# Design Token Execution: Remove Legacy And Next Layer

Date: 2026-04-11

## Scope

- Removed the legacy token tree from `src/constants/theme-tokens.json`.
- Removed the top-level `next` wrapper from `src/constants/theme-tokens.json`.
- Removed legacy utility generation from `tailwind.config.js`.
- Removed `next-` prefixes from token utility generation.
- Removed `--next-*` CSS variable generation.
- Replaced source token utilities with final unprefixed forms:
  - `next-semantic-*` to `semantic-*`
  - `next-component-*` to `component-*`
  - `bg-next-gradient-*` to `bg-gradient-*`
  - `shadow-next-shadow-*` to `shadow-*`
  - `shadow-next-*` to `shadow-*`
- Rewrote `scripts/generate-token-docs.js` for the root-level token system.
- Deleted `src/constants/theme-token-meta.json` because it only served the legacy token docs flow.

## Token Decisions

- Shadow utilities now use final Tailwind names such as `shadow-panel`, `shadow-hero`, and `shadow-about-hero-panel`.
- Added `effect.shadow.hero` for shared hero and overlay panel elevation.
- Added dark `component.hero-secondary-action.background-hover` to match the existing light theme token.
- `palette` remains internal token authoring data and does not generate Tailwind utilities.

## Validation

- `npm run generate:token-docs` passed.
- `npm run type-check` passed.
- `npm run build:h5` passed.
- Generated token docs reported:
  - unknown token utility references: `0`
  - residual next-prefixed token references: `0`
  - token opacity suffix references: `0`
- Final token data roots are `palette` and `themes`.
- Final utility samples generated by Tailwind:
  - `bg-semantic-page-default`
  - `text-component-directory-control-selected-text`
  - `bg-gradient-home-hero`
  - `shadow-panel`
