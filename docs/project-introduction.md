# 相亲平台项目介绍

## 项目是什么

这个项目是一个面向婚恋与长期关系场景的前台演示站，不是泛娱乐社交产品，也不是单纯的信息展示页。

它围绕“认真相识、线下推进、家庭边界、会员服务”这四条主线来组织页面和内容，目标是把一个相亲平台最核心的前台体验先搭出来。

## 项目定位

项目当前的定位可以概括为：

- 一个强调长期关系而不是即时娱乐的相亲平台
- 一个同时支持“本人主导”与“家长有限协同”的婚恋产品
- 一个以巴黎与欧洲场景为品牌起点、但可面向更广泛国际用户的演示型站点
- 一个先完成前台浏览、转化和账户体验，再逐步补齐真实业务能力的产品原型

## 解决什么问题

这个项目想解决的不是“如何让用户刷得更久”，而是下面这些更接近婚恋实际的问题：

- 用户如何更体面地展示自己，而不是陷入低质量浏览
- 如何把资料筛选、活动报名、消息沟通和会员升级串成一条完整链路
- 如何在婚恋场景里给家长保留合理位置，但不让家长替代本人决策
- 如何通过活动和线下场景，把线上兴趣真正转成现实接触

## 目标用户

当前目标用户不是泛人群，而是相对明确的一类人：

- 对长期关系、婚恋或稳定发展有明确意图的单身用户
- 更关注资料质量、价值观、生活节奏和现实匹配度的人
- 接受更克制、更有边界感的产品体验，而不是纯情绪刺激的人
- 在部分阶段愿意让家庭辅助了解，但仍坚持本人主导的人

同时，平台也为另一类使用者保留了入口：

- 家长或家庭成员
  只能在被授权的范围内了解资料、理解节奏、辅助判断，不是第二套主控账号

## 当前产品结构

项目当前主要由五个部分组成。

### 1. 公共品牌层

- 首页
- 项目介绍页
- 会员体系页
- 联系页

这部分负责讲清楚平台是谁、服务谁、为什么存在，以及用户为什么愿意继续往下看。

### 2. 发现层

- 本人视角资料列表与详情
- 家长视角资料列表与详情

这部分是项目的核心差异之一。
同样是看资料，但本人视角强调关系判断与个人匹配，家长视角强调家庭边界、背景理解和辅助决策。

### 3. 活动层

- 活动列表
- 活动详情

活动不是装饰内容，而是平台把“线上浏览”推进到“线下接触”的关键一层。

### 4. 转化层

- 登录
- 注册
- 会员升级

这部分负责把品牌兴趣、资料浏览和活动兴趣收口到真正的注册与服务转化上。

### 5. 账户层

- 账户总览
- 我的资料
- 我的报名
- 我的收藏
- 消息沟通
- 隐私授权

账户层已经不再是通用用户中心，而是围绕婚恋过程本身组织：

- 资料质量
- 收藏判断
- 活动推进
- 消息边界
- 家庭协同权限

## 这个项目最重要的产品语义

### 1. 本人主导

这是当前项目最核心的原则。

无论是资料、收藏、活动还是消息，真正做决定的人都应该是用户本人。
平台可以提供服务、顾问、会员能力和家庭辅助，但不能把这些辅助误写成“替代本人”。

### 2. 家长有限协同

这个项目不是把家长从婚恋流程里完全剔除，而是给家长一个被严格限制、被明确授权的角色。

也就是说：

- 可以辅助了解
- 可以补充背景
- 可以帮助判断节奏
- 不能替代本人筛选
- 不能替代本人沟通
- 不能替代本人做关系决定

### 3. 线下推进

线上资料和消息只是前半段。
真正让平台更像婚恋产品而不是普通社交产品的，是活动和线下接触这层能力。

### 4. 会员服务不是简单卖权限

会员体系的意义不只是“多看几个资料”。
它更接近服务深度的分层，包括：

- 更强的资料支持
- 更明确的活动机会
- 更深的顾问辅助
- 更高质量的推进效率

## 当前项目状态

从项目实现上看，它现在属于一个前台演示型产品原型，已经具备较完整的页面骨架和语义层，但还没有进入完整业务系统阶段。

当前已经具备的部分：

- 多语言前台页面
- 品牌页与介绍页
- 本人 / 家长双视角资料浏览
- 活动浏览与详情
- 会员体系与注册入口
- 账户页与隐私边界
- 基于 token 的统一视觉系统

当前仍然以演示为主的部分：

- 数据仍以 mock 为主
- 登录、支付、审核、消息会话等真实业务能力未完整接入
- 顾问流程与后台管理能力还没有落地

## 为什么这个项目值得继续做

这个项目的价值不在于页面多，而在于它已经形成了一套相对清晰的婚恋产品结构：

- 公共品牌页建立信任
- 资料页承担筛选
- 家长页承担辅助
- 活动页承担线下推进
- 账户页承担用户主流程收口

这意味着它后续可以沿着明确方向继续深化，而不是反复堆页面。

如果继续往下做，最值得优先补的不是新的展示页，而是更真实的业务能力，例如：

- 登录与身份状态
- 筛选与排序
- 报名与支付
- 消息会话
- 顾问跟进
- 权限与审核

## 对外一句话介绍

如果要用一句话介绍这个项目，可以写成：

“这是一个以长期关系为目标、由本人主导并支持家长有限协同的相亲平台前台原型，围绕资料筛选、活动推进、会员服务和关系边界来组织整体体验。”
